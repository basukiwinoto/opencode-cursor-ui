# Changelog

## 0.1.1

- Documentation refresh: Marketplace install instructions, multi-tab chat + inline sessions pane,
  per-message fork/copy, in-app provider setup (API key + custom providers), default model/agent
  config writes, compact Control Center descriptions.

## 0.1.0 — Initial release

- Cursor-style Agent/Chat sidebar for OpenCode (streaming replies, markdown, tool calls,
  reasoning sections, permission cards, file changes with native diffs).
- OpenCode runtime lifecycle: detect, install (managed, integrity-verified), start, stop,
  restart, update, reconnect; external-server mode.
- Sessions: history, resume, rename, delete, drafts, model/agent pickers.
- Editor integration: selection/file context, diagnostics counts, pre-edit snapshots.
- Runtime Control Center with redacted diagnostic logs.
- Security: strict webview CSP, validated messages, SecretStorage, Workspace Trust gating.
